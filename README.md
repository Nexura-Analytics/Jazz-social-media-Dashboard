Jazz Social Media Analytics Dashboard

Project Overview
This project is a complete data analysis dashboard designed to monitor and evaluate Jazz social media customer interactions, ticket handling performance, and service efficiency.

Key Features
- MTD Ticket Analysis (Within TAT, After TAT, Total)
- Live Ticket Monitoring
- Performance Metrics (ASA, Available Agents, Pending Queries)
- Service Level Tracking (Live, Day-1, MTD)
- Ticket Category Analysis (Complaint, Information, Suggestions, Service Requests, Others)
- Tag-Level Insights
- Top 10 Issues Analysis

Tools & Technologies
- Google Sheets
- Looker Studio
- Excel
Insights
- Platform-wise complaint trends
- SLA performance tracking
- Customer issue identification
- Team efficiency monitoring

Business Impact
- Improves response time
- Enhances customer satisfaction
- Supports decision-making
- Identifies process gaps

Future Improvements
- Automated data pipeline
- Real-time data integration
- Predictive analytics
- SLA alert system
